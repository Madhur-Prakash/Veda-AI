# VedaAI Frontend Prototype

This folder contains the Next.js 15 prototype that reproduces the provided VedaAI screenshots.

## Run

```bash
cd frontend
npm install
npm run dev
```

## Routes

- `/` empty assignments state
- `/assignments` assignments grid view
- `/create` assignment creation flow
- `/output` generated paper preview
- `/toolkit`, `/groups`, `/library`, `/settings` placeholder shell routes

## Notes

- The UI is built as a screenshot-led static prototype.
- The shared shell, header, and sidebar match the visual language from the handoff images.
